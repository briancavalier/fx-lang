# Phase 2.6 work plan

Date: 2026-06-09

## Purpose

Phase 2.6 adds two small quality-of-life surface forms before Phase 3 effects:
data-last pipeline calls and Koka-style prefix `with` trailing-action sugar.
Both forms are pure desugarings into existing calls and lambdas.

## Scope

Include:

- `|>` as left-associative data-last call sugar;
- prefix `with` as final action/thunk sugar;
- flat stacked `with` headers;
- parser, checker, lowerer, JavaScript compiler, CLI, examples, and docs;
- acceptance tests proving generated JavaScript executes under Node.

Defer:

- effect declarations, effect rows, handlers, resumptions, scoped effects, and
  coeffects;
- postfix `with`;
- placeholders, partial application, function composition, receiver sugar, and
  Koka-style dot application.

## Surface rules

Pipeline appends the piped value to the rightmost ordinary argument position:

```fx
value |> f
value |> f()
value |> f(arg)
value |> module.f(arg)
```

desugars to:

```fx
f(value)
f(value)
f(arg, value)
module.f(arg, value)
```

Prefix `with` appends a zero-argument action thunk:

```fx
with f(args)
  body
```

desugars to:

```fx
f(args, () -> body)
```

Pipeline composes inside a `with` target before the action thunk is appended:

```fx
with config |> with-logger(level)
  run()
```

desugars to:

```fx
with-logger(level, config, () -> run())
```

Flat stacked `with` headers desugar outermost-first:

```fx
with config |> with-logger(level)
with catch-errors(default)
  run()
```

desugars to:

```fx
with-logger(level, config, () ->
  catch-errors(default, () ->
    run()
  )
)
```

## Acceptance

- Phase 2.6 examples parse, check, compile, and run under Node.
- Pipeline type checking matches the equivalent explicit call.
- Prefix `with` type checking matches the equivalent explicit final-action
  call.
- The compiler lowers both forms to existing core call/lambda IR without adding
  runtime helpers.
